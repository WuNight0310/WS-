# Weiß Schwarz 卡牌對戰模擬系統 (Master Duel 全螢幕風格版)

支援《怕痛的我，把防禦力點滿就對了 (BFR/S78)》、《GA文庫 (GA/S131)》、《孤獨搖滾！(BTR/W107)》三大系列完整規則、高低版本異畫/簽卡、單人 AI 對戰與雙人區網/外網連線對戰。

## 方式一：免安裝 EXE 版（推薦分享給朋友）
1. 在你的電腦雙擊執行 **`一鍵打包成EXE執行檔.bat`**。
2. 打包完成後，將產生的 **`dist/WS_CardBattle`** 資料夾壓縮成 `.zip` 傳給朋友（或上傳到 GitHub Releases / Google 雲端硬碟）。
3. 朋友解壓縮後，直接雙擊 **`WS_CardBattle.exe`** 即可遊玩，完全不需要安裝 Python！

## 方式二：使用 Python 直接執行
```bash
pip install pillow pygame requests
python main.py
```
