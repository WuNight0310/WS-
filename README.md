# Weiß Schwarz 卡牌對戰模擬器

基於 Python 與 Tkinter 開發的 Weiß Schwarz 卡牌對戰模擬器，支援電腦端直接執行與 Android 手機端打包安裝。

## 功能說明

### 1. 對戰規則與階段流程
- 完整實作起始手牌調度、站立階段、抽牌階段、時鐘階段、主要階段、名場面階段、攻擊階段、安可階段與回合結束階段。
- 內建傷害取消判定、升等選卡、牌庫抽乾洗牌與懲罰傷害、角色倒置與離場處理。
- 支援判牌觸發標記效果，包含魂傷、木門、城門、開機、書、金磚、金袋、風、射擊與箭頭。

### 2. 中文效果解析與自動執行
- 內建中文卡片效果解析器，自動將繁體中文效果文轉換為結構化能力條件、代價與執行動作。
- 支援【永】、【自】、【起】、【CX連動】與【反擊】助太刀或事件卡。
- 涵蓋牌組檢索、看頂濾牌、休息室回收、集中、前後列應援、早出降等、擊倒放時鐘或能量區、追加燒血、治療與雙重判牌等機制。

### 3. 卡組編輯器
- 採用左、中、右三欄配置：左側顯示卡片圖片、數值與效果文，中間顯示目前 50 張卡組內容，右側顯示系列卡池與篩選工具。
- 滑鼠左鍵點擊卡片可查看詳細效果，滑鼠右鍵點擊右側牌庫卡片可加入卡組，右鍵點擊中間卡組卡片可移出卡組，下方亦保留加減按鈕供觸控操作。
- 支援依系列、顏色、等級、魂傷、攻擊力與高低稀有度版本篩選，並可一鍵切換整副卡組的一般版與高版本卡圖。

### 4. 貓罐子系列與社群牌組匯入
- **系列卡表擴充**：連線讀取貓罐子系列清單，可選擇單次抓取完整系列或以每次 20 張分批匯入至 `sets/` 目錄，並於背景自動下載卡圖。
- **社群牌組匯入**：支援搜尋貓罐子公開社群牌組，或直接貼上牌組網址與 5 碼牌組代碼。匯入的 50 張配比只會註冊至玩家的自訂卡組清單，不會覆寫或變動已匯入的系列卡池與預設套牌。

### 5. 對戰模式與連線機制
- **單人練習**：內建 AI 對手，會自動進行調度、出牌、集中、連動與攻擊階段決策，並可在設定中調整 AI 翻牌間隔秒數。
- **雙人連線**：支援區域網路直連、Radmin VPN 虛擬區網與 Playit.gg 公開通道連線。雙方僅同步出牌與場面操作指令，隨機種子與切洗結果會透過狀態封包保持一致。

### 6. 個人化與音效設定
- 支援更換對戰桌布、調整背景暗化比例、更換卡套樣式與上傳自訂圖片。
- 內建互動式圓框頭像裁切器，可從卡池任選卡圖拖曳與縮放作為玩家頭像。
- 支援獨立開關與調整主選單、主要階段、戰鬥階段背景音樂，以及點擊、抽卡、扣血、名場面音效音量。

## 目錄結構

| 檔案或資料夾 | 用途說明 |
| :--- | :--- |
| `main.py` | 主程式介面、卡組編輯器、對戰畫布、音效管理與圖片快取 |
| `engine.py` | 遊戲規則引擎、中文效果解析器、AI 決策邏輯與貓罐子匯入模組 |
| `network.py` | TCP 雙人連線模組，管理房間建立、加入與封包佇列 |
| `tk_android_bridge.py` | Android 端 Kivy 轉接層，負責觸控事件與畫面繪製轉換 |
| `sets/` | 存放各系列 JSON 卡表資料 |
| `ws_card_images/` | 卡片圖檔本地快取目錄 |
| `ws_audio/` | 背景音樂與遊戲音效檔案目錄 |
| `custom_decks_book.json` | 儲存玩家自訂卡組與匯入的社群牌組配比 |
| `user_settings.json` | 儲存玩家名稱、頭像、卡套、桌布與音量設定 |

## 電腦端環境與啟動方式

### 1. 環境需求
- 作業系統：Windows 10 / 11、macOS 或 Linux
- Python 版本：Python 3.10 以上
- 依賴套件：`pillow`、`pygame`

```bash
pip install pillow pygame
```

### 2. 啟動遊戲
- Windows 使用者可直接雙擊執行 `啟動遊戲.bat`。
- 或於終端機執行：

```bash
python main.py
```

## Android 版本編譯

專案內含 `buildozer.spec` 與 `.github/workflows/build_apk.yml`，推送至 GitHub 後可透過 GitHub Actions 自動執行 Buildozer 編譯出 Android APK 安裝檔。
